billcheck
Why Demo Checks PDFs Limits

An invoice can add up and still be wrong.

Docsumo costs about ₹25,000 a month and reads English only. billcheck is free, runs offline, reads Devanagari, Gujarati and Tamil digits, and does the one thing a field-extraction service does not: it checks the arithmetic of every line against the tax the invoice charges.

$ pip install billcheck && billcheck invoice.pdf

The ₹12 that a total-only check cannot see

Somebody corrected the CGST figure on this bill and forgot the SGST. The printed total is perfectly consistent with the printed tax — so every tool that reconciles the total passes it. The bill is still wrong.

What the invoice prints

Taxable value     67,200.00
CGST               2,226.00
SGST               2,214.00
                  ---------
Invoice total     71,640.00

67,200 + 2,226 + 2,214 = 71,640. Adds up. Passes a total check.

What the line items say

54,000 @ 5%   =  2,700.00
10,800 @ 12%  =  1,296.00
 2,400 @ 18%  =    432.00
                ---------
tax implied       4,428.00
tax charged       4,440.00   ← ₹12 over

And CGST should equal SGST. It does not.

    FAIL  CGST and SGST are equal, and IGST is not mixed in

Try the totals

The three checks that need nothing but the totals, running in this page. The line-item checks — the ones that find the ₹12 — need the invoice, so they run in the command line.

Rounding allowance: ₹1.00, the same default as the command line. For ₹12 of tax error the totals look fine — which is exactly the point.

Twelve checks

Nine are arithmetic. The other three are about whether the bill can be filed at all.

01Supplier GSTIN is validwrong check character, unassigned state code, impossible PAN
02Buyer GSTIN is validthe same, for B2B bills; skipped on a B2C bill
03Every line: quantity × rate = taxablea line that says 55,000 where 120 × 450 is 54,000
04Lines add up to the taxable valuean item left out of the summary
05Tax charged = the tax the line rates implythe ₹12 above; the rates are solved for when the bill prints none
06CGST = SGST, and IGST is not mixed inhalf a correction applied
07Place of supply agrees with the tax splitIGST on a sale inside one state
08Taxable + tax + round-off = totala total that does not add up
09Amount in words = amount in figuresthe failure that bounces a cheque
10Line items were founda silent, partial read
11HSN codes presenta bill that cannot be filed
12Invoice number and date presenta bill that cannot be posted

Limits, stated

A tool that hides its edges is worse than a small tool that names them.

  • No OCR. A scanned bill has no text layer and is refused with NoTextLayer rather than guessed at.
  • Layouts move. Row reconstruction is general, but every new template is a test case. Ten samples ship, each with its expected verdict pinned in the test suite.
  • Register CSV, not Tally XML. Tally's XML import is version-sensitive and is not claimed.
  • An inferred rate is an inference. When a bill prints no rate column the rates are recovered from the totals, and reported as a warning rather than a pass.
  • Arithmetic, not law. It cannot tell you whether the rate is right for those goods, whether the supply happened, or whether e-invoicing applied.
  • English and Hindi labels. Devanagari, Gujarati, Tamil and Arabic-Indic digits are read; label sets are a dictionary entry per script.

Run it

shell
# install
pip install billcheck

# one invoice
billcheck invoice.pdf

# a folder, with a register CSV for Tally and a review sheet
billcheck *.pdf --csv register.csv --review review.md

# exit codes: 0 clean, 1 something failed, 2 the run broke
billcheck invoices/ --quiet && echo "all clear"
